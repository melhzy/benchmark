How it was measured

Each language implements the same specification: the same algorithms, the same inputs (generated from one formula, not each language's random generator) and the same output format. Loop-heavy tests use smaller sizes in Python and R, and every result is a rate (work per second), so sizes don't affect the comparison. Each test runs five times after a warm-up; the median counts. The figures above come from the newest full run of each language; the run-to-run spread is in the tooltips ({{spread_text}}).

Before each language, the runner waits for the CPU to cool below 60 °C. {{power_text}} {{verify_text}}

To add a machine, clone the repository and run:

./run_all.sh --check     # what is installed, per language
./run_all.sh             # {{minutes_text}}; results go to results/<machine>/

Full definitions are in common/SPEC.md, and the analysis notebook with more charts is analysis.ipynb.
