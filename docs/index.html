Four languages, two laptops

The same 18 tests, written in C++, Python, R and JavaScript, run on two laptops — Dell Inspiron 14 7425 2-in-1 on Linux and Alienware m16 R1 on Windows — to see how each language uses a computer's CPU, memory and GPU.

    What the numbers say

      How it was measured

      Each language implements the same specification: the same algorithms, the same inputs (generated from one formula, not each language's random generator) and the same output format. Loop-heavy tests use smaller sizes in Python and R, and every result is a rate (work per second), so sizes don't affect the comparison. Each test runs five times after a warm-up; the median counts. The figures above come from the newest full run of each language; the run-to-run spread is in the tooltips (on the , ).

      To add a machine, clone the repository and run, on Linux:

      ./run_all.sh --check     # what is installed, per language
./run_all.sh             # full run; results go to results/<machine>/

      or on Windows (PowerShell or cmd):

      powershell -ExecutionPolicy Bypass -File setup_windows.ps1   # OpenBLAS, OpenCL SDK, packages
.\run_all.cmd --check
.\run_all.cmd

      Full definitions are in common/SPEC.md, and the analysis notebook with more charts is analysis.ipynb.
